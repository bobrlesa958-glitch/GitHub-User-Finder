# GitHub User Finder

Автор: Гренко Светлана Михайловна 

Описание:  
GitHub User Finder — это десктопное приложение с графическим интерфейсом для поиска пользователей GitHub. Приложение позволяет искать пользователей по логину, добавлять их в избранное, удалять из избранного и сохранять список избранных пользователей в JSON-файл.

Как использовать API:
Приложение использует публичный REST API GitHub. Для поиска пользователей отправляется GET-запрос на эндпоинт:  
`https://api.github.com/search/users?q={query}&per_page=30`  

Параметры:
- `q` — поисковый запрос (имя пользователя)
- `per_page` — количество результатов на страницу (максимум 30)

API возвращает JSON-объект с полем `items`, содержащим массив пользователей. Для каждого пользователя извлекаются поля `login` и `id`.

API не требует аутентификации для базового поиска, но имеет ограничение: 60 запросов в час без токена доступа.

**Примеры использования:**

1. Поиск пользователя:  
   В поле ввода введите "octocat" и нажмите кнопку "Поиск" или клавишу Enter. В таблице отобразятся найденные пользователи.

2. Добавление в избранное:  
   Выберите пользователя в таблице результатов и нажмите "Добавить выбранного в избранное". Пользователь появится в списке избранных.

3. Удаление из избранного:  
   Выберите пользователя в списке избранных и нажмите "Удалить выбранного из избранного".

4. Сохранение данных: 
   Все избранные пользователи автоматически сохраняются в файл `favorites.json` в той же директории, что и программа. При следующем запуске список избранных восстановится.

Возможные тесты (для проверки):

- **Тест 1 (пустой поиск):** Оставить поле ввода пустым и нажать "Поиск" → появляется предупреждение "Поле поиска не должно быть пустым".
- **Тест 2 (несуществующий пользователь):** Ввести "qwertyuiopasdfghjklzxcvbnm123456" → сообщение "Пользователи не найдены".
- **Тест 3 (добавление в избранное):** Найти пользователя "mojombo", добавить → появляется подтверждение, пользователь появляется в списке избранных.
- **Тест 4 (дублирование):** Попробовать добавить того же пользователя повторно → сообщение "Уже в избранном".
- **Тест 5 (удаление из избранного):** Выбрать пользователя в списке избранных и удалить → подтверждение удаления, пользователь исчезает из списка.
- **Тест 6 (сохранение в JSON):** Добавить пользователя в избранное, закрыть программу, проверить наличие файла `favorites.json` с корректными данными.
- **Тест 7 (загрузка из JSON):** Удалить пользователя из избранного в интерфейсе, снова добавить того же пользователя → файл обновляется корректно.
